# workshop-passport-demo

Uchebnyy repozitoriy Proektnoy masterskoy (demo).
Zaglushki pod passport proekta — shtoby pokazat strukturu.

## Chto tut

| Papka / fayl | Zachem |
|---|---|
| `docs/idea.md` | Ideya i problema (zaglushka) |
| `docs/audience.md` | Celevaya auditoriya |
| `docs/analogs.md` | Tablica analogov s GitHub |
| `docs/mvp.md` | Minimalnyy prototip |
| `src/placeholder.txt` | Mesto pod budushchiy kod |

## Kak ispolzovat shkolniku

1. Skopiruy strukturu v svoy repozitoriy.
2. Zameni zaglushki tekstom iz pasporta.
3. Polozhi ssylki na 10 analogov v `docs/analogs.md`.
